# ④ 구현 검증 체크리스트

`git diff`(새 파일은 `git status`로 확인 후 직접 읽기), `01-plan.md`, `03-build-notes.md`를 대조한다. 결과는 `04-code-review.md`.

## A. 계획 일치

| # | 항목 | 실패하면 |
|---|---|---|
| A1 | 바뀐 파일이 계획의 "바꿀 파일"과 일치한다. 추가된 파일은 build-notes에 이유가 있다 | REVISE |
| A2 | 계획의 "먼저 쓸 테스트"가 전부 작성됐다 | REVISE |
| A3 | "하지 않는다"로 적힌 일을 하지 않았다 | REVISE |
| A4 | diff에 들어간 정책 규칙 · 검사마다 그것이 거부로 떨어지는 테스트가 하나 이상 있다(rego-policy '규칙당 거부 한 개'). **여기서 '규칙'은 판단 결과를 바꿀 수 있는 조건 한 줄이다(예: `is_string(input.args.body)`). 헬퍼 안의 중간 단계(타입 확인 뒤의 `split`, 값 계산 등)는 따로 세지 않는다.** (작업 D H4) | REVISE |

## B. 불변 원칙 (`broker-invariants` 금지 패턴 대조)

변경된 코드 경로마다 확인한다. 위반은 `파일:줄`과 원칙 번호로 적는다.

| # | 확인 방법 |
|---|---|
| B1 | 모든 `except` · 기본값 · 분기에서 기본 결과가 `deny`인가. `!= "deny"` 형태의 허용 판정이 없는가 |
| B2 | 외부 호출에 타임아웃이 있는가 |
| B3 | 응답 · 로그 · 오류 메시지에 자격 증명이 새지 않는가 |
| B4 | 확인과 차감이 분리된 곳이 없는가 (조회 후 조건문 후 쓰기) |
| B5 | 판단 저장과 outbox가 같은 트랜잭션인가. 거부 경로도 기록되는가 |
| B6 | 캐시가 위임 버전 없이 TTL에만 의존하지 않는가 |
| B7 | 테스트가 결과와 이유를 둘 다 assert하는가. 도구 미호출을 확인하는가 |

## C. 기본 정확성

| # | 항목 |
|---|---|
| C1 | 비동기 코드에서 await 누락, 공유 상태 경쟁 |
| C2 | 비밀 값이 코드 · 테스트 · `env.example` 값에 하드코딩되지 않음 |

## D. 증거

| # | 항목 |
|---|---|
| D1 | `03-build-notes.md`의 자기 점검 결과마다 `evidence/build-…` 증거 파일이 있고, 적힌 결과(종료 코드 · 통과 수)가 로그 원문과 같다 |
| D2 | "실패 먼저 확인"(테스트가 구현 전에 실패했음) 증거 로그가 있다 |
| D3 | `evidence.py <run 폴더> --verify`가 전부 "일치"다 (직접 실행해 확인) |
| D4 | **탐침:** 보안 관련 검사(권한, 실패 무시 금지, fail-closed)를 하는 테스트는 대상 파일의 **임시 사본**(스크래치 폴더, 원본 수정 금지)에서 그 조건을 깨 보고 테스트가 실패하는지 확인한다. 깬 방법 · 결과를 04에 적고, 가능하면 `evidence.py … review-probe-<라벨>`로 남긴다. 통과해 버리면 A2(테스트가 계획보다 약함)로 REVISE. red · 탐침 로그에 테스트 러너의 결과 요약 줄(opa `PASS:` · `FAIL:` 줄, pytest 요약 줄)이 없으면 **무효 실행**이다. 종료 코드가 0이 아니어도 red 증거로 쓰지 않는다. 무효 로그 번호와 이유를 03 · 04에 적고 같은 라벨로 다시 실행한다(채점은 마지막 로그). Git Bash에서 컨테이너 안 절대경로(`/policies`, 탐침 사본 경로 등)를 넘길 때는 `MSYS_NO_PATHCONV=1`을 붙인다. 경로 변환을 끄는 설정이지 권한 우회가 아니다. (작업 D H12-2 · H12-3) |

## 판정

- D 항목이 하나라도 실패하면 최소 REVISE ("했다"는 서술만 있고 증거가 없음). `--verify`에 "변조됨"이 있으면 BLOCK
- B 항목 위반이 하나라도 있으면 최소 REVISE
- 위반을 "개발 편의" · "나중에 고침"으로 정당화하는 주석 · 플래그가 있으면 BLOCK
